# PRD — Chaitanya Pawaskar Portfolio

## Original Problem Statement
A clean, project-first portfolio website positioning Chaitanya Pawaskar as a multidisciplinary product & industrial designer. Target users: recruiters and design managers. Pages: Home (hero, credibility strip, 3 featured projects, additional work, 5-step process, closing CTA), Work index with filters, case-study detail pages (10-section framework), About, Resume (PDF download), Contact (form + email/LinkedIn). Visual: minimalist, high-contrast, off-white base, single restrained accent. Stack: React + FastAPI + MongoDB; contact form via managed email.

## Architecture
- Frontend: React (CRA/craco), Tailwind, framer-motion, react-router. Content in `src/data/projects.js` (7 projects) + `src/data/site.js`. Real project images extracted from user-supplied PDF, served from `frontend/public/assets/projects/`.
- Backend: FastAPI `server.py` — `/api/health`, `POST /api/contact` (Mongo `contact_messages` + honeypot + Resend proxy notification), `GET /api/resume` (PDF FileResponse).
- DB: MongoDB via MONGO_URL. Email: Emergent managed Resend proxy (`EMERGENT_EMAIL_KEY`, `EMAIL_FROM_NAME`, `OWNER_EMAIL` in backend/.env).
- Resume PDF generated by `/app/scripts/generate_resume.py` (fpdf2) → `backend/static/Chaitanya_Pawaskar_Resume.pdf`.

## User Personas
- Recruiters hiring product/industrial/design-research talent
- Design managers at tech/consumer-product companies and agencies
- Industrial design & innovation teams evaluating process quality
- Collaborators in systems thinking and human-centered product development

## Core Requirements (static)
- Project-first homepage, 3 featured projects, secondary work list, process preview, closing CTA
- Consistent 10-section case-study framework per project
- About page with narrative, education, experience, capabilities, tools, recognition
- Downloadable resume; contact form with email notification
- Responsive, accessible (focus states, alt text, 44px tap targets), data-testids on interactive elements
